# 拾伍 · 五子棋

一个完全离线的 Electron 五子棋桌面 App：木纹棋盘、黑白棋子，以及一点舒缓的音乐。

## 启动

需要 **Bun**、**Node.js ≥ 22.12** 和 **just**。

```sh
cd /Users/szou/Python/Playground/LearnTopEngSkills/practice/harness-dual-loops/vendor/pi-vs-claude-code/apps/five
just
```

`just` / `just start` 会安装依赖、准备 Electron 运行时并打开桌面窗口。首次安装需要网络；之后对弈与音乐都不需要联网。

不使用 just 也可以：

```sh
bun install
bun run start
```

> Electron 45 需要显式安装运行时，项目已通过 `postinstall` 自动处理。如果安装时禁用了生命周期脚本，运行 `bun run postinstall`。

## 对弈

- **经典棋盘**：15×15 交叉点、五颗星位、坐标标记、立体黑白棋子。
- **规则**：黑棋先行，横、竖或斜向连续五子及以上获胜。不设三三、四四、长连等禁手；全盘落满且无胜者则和棋。
- **三级人机**：
  - **入门**：在合理候选中随机选择，节奏轻松。
  - **进阶**：最多两层搜索，兼顾进攻与防守。
  - **高手**：迭代加深、Alpha-Beta 剪枝，最多四层搜索，约 1.4 秒计算预算。
  - 所有难度都会优先完成直接获胜的一手或阻挡对手下一手成五。AI 使用局部候选和启发式评估，并非专业竞赛引擎。
- 可选择黑棋先手或白棋后手；白棋模式由 AI 自动开局。
- **悔一步**撤回你上一手以及 AI 的回应；AI 思考中也可悔棋，不会出现过期落子。
- 切换难度、执子或重开时，尚未结束的对局会弹出确认提示。
- 可显示所有棋子的落子顺序；默认以红色小点标记最后一手，胜利时标出连珠。
- 棋局、难度、执子、音乐和音量自动保存在 Electron 本机用户数据目录，重开应用可续局。

### 键盘

点击棋盘或用 Tab 聚焦后：方向键移动，Enter / 空格落子。`⌘ Z`（macOS）或 `Ctrl Z` 悔棋。

## 舒缓背景音乐

棋盘下方可选择：

- **轻柔钢琴**：66 BPM 的柔和分解和弦与旋律。
- **慢爵士**：62 BPM 的温暖电钢琴式和弦、低音、轻刷鼓与摇摆节奏。

两种音乐均为 **Web Audio 实时合成的原创循环编配**，不是录制的原声钢琴或商业歌曲；没有外链音频和版权素材依赖。带轻混响、切换淡入淡出，以及独立的 0–100% 音量控制。顶部的音符按钮仅控制落子音效，与背景音乐互不干扰。

默认音乐关闭，选择风格即可播放。恢复上次的音乐偏好后，可能需要轻点页面或按键以满足浏览器的音频自动播放限制。

## 验证

```sh
just test     # 游戏规则与三级 AI 单元测试
just smoke    # 实际启动 Electron 的 UI / Worker / 音乐冒烟测试
just check    # 全部测试
```

冒烟测试使用独立临时用户目录，不会修改你的棋局；覆盖鼠标和键盘落子、真实 AI Worker、思考中悔棋/重开、先后手、自动续局、胜局、音乐切换与音符调度、音量保存和窗口缩放，测试结束后自动关闭窗口。

## 代码结构

```text
main.cjs                 Electron 主进程与安全窗口配置
src/game.mjs             纯游戏规则、复盘与悔棋
src/ai.mjs               棋形评估、候选点、限时搜索
renderer/index.html      中文界面
renderer/styles.css      木色棋盘与墨绿 UI
renderer/app.mjs         Canvas 绘制、交互、持久化
renderer/ai-worker.mjs   独立线程 AI
renderer/audio.mjs       钢琴 / 慢爵士合成器与落子音效
test/                    规则、AI 与真实 Electron 测试
```

渲染进程开启沙箱、上下文隔离与 CSP，禁用 Node 集成，不暴露文件系统或任意 IPC。没有后台服务、账号、API Key 或遥测。
