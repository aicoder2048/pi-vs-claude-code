# 楚河：规则与计时约定

本应用采用常见中国象棋基本走法及明确的简化竞赛裁定，不是正式赛事裁判系统。

## 棋盘与坐标

- 9 路 × 10 行，棋子走交叉点，红先黑后。
- 业务坐标 `x=0..8`（A..I）、`y=0..9`。黑方底线 y=0，红方底线 y=9。棋盘翻转只影响显示，不改变棋谱或模型坐标。
- 红方九宫 x=3..5、y=7..9；黑方九宫 x=3..5、y=0..2；河界位于 y=4 与 y=5 之间。
- 两方各将帅 1、士仕 2、象相 2、马 2、车 2、炮 2、兵卒 5。

## 走法

| 棋子 | 走法及限制 |
|---|---|
| 将 / 帅 | 九宫内横直一步，禁止将帅同路无子阻隔。将帅照面视为被将军。 |
| 士 / 仕 | 九宫内斜一步。 |
| 象 / 相 | 斜走两步（田字）；中间象眼不可有子；不可过河。 |
| 马 | 日字；长方向相邻的马腿不可被任何棋子占据。 |
| 车 | 横直任意距离，中间不可有子。 |
| 炮 | 不吃子时与车相同；吃子时起终点之间必须恰有一枚炮架，炮架颜色不限。 |
| 兵 / 卒 | 向前一步；过河后也可横走一步；永不后退。 |

不能吃己方棋子，不允许不动或轮空。任何一步都不能令己方将帅处于敌方攻击中；被将军时必须通过合法移动应将。将帅安全通过攻击几何和全盘检查验证，不允许先吃将帅再判断。

## 终局

- **将死**：行棋方被将军且没有合法走法，判负。
- **困毙**：行棋方没有合法走法但未被将军，仍判负（与西洋棋不同）。
- **超时**：棋钟恰好耗尽或已耗尽即负，不等下一次 UI 刷新；不能靠迟到吃子或迟到将死反转结果。
- **认输**：人类可主动认输，本局算大模型胜。
- **重复**：相同棋子分布和相同行棋方第三次出现时，检查最近三个相同局面之间的循环：若恰有一方在该区间每一手均将军，则此方长将判负；否则和棋。相同种类棋子的身份 ID 不参与重复判定。
- **自然限着简化**：连续 120 半回合（双方共走 120 手）没有吃子且没有兵卒移动则和棋；吃子或兵卒移动重置计数。
- 当同一步达到多个条件，先裁定将死 / 困毙，再裁定重复，再裁定自然限着。超时在接受走子之前检查。

### 未实现的裁判条款

没有完整的长捉、捉子价值、将捉混合、循环追捉或裁判介入规则；没有所有理论例和的自动识别，也没有双方协商和棋。120 半回合规则是本应用的简化约定，并非对正式规则中所有限着细节的复刻。

## 棋钟

默认双方各 30 分钟包干，不加秒。可在新比赛设置中调整局时，或切换为 Fischer 每完成一手加 0–60 秒。

- 每局从红方开始计时；只扣当前行棋方的时间。
- 业务主进程权威计时，使用单调时基，200ms 心跳推送只负责通知 UI。收到人类走子、工具提交、取消 / 重试等操作时均先核对截止时间。
- 显示向上取整到秒；例如剩 1ms 显示 00:01，但到 0ms 就判负。
- Fischer 加秒在及时且合法的非终局走子提交后发放；非法走法、悔棋和重试不发放。终局后时钟停止，无需再加秒。
- LLM 网络、思考、工具试算及重试等待均计时。取消模型请求不是暂停比赛。打开设置、回看、切换模型也不停钟。
- 不另设单步时限，取消了应用层固定 90 秒模型回合技术超时。单步可以长考数分钟甚至更久，但必须在当前方余时耗尽前完成合法提交，不能用落子后的 20 秒加秒补救已经超时的走法。
- 主进程棋钟耗尽、手动取消或局面失效会中止 Pi 请求及搜索；供应商 / 网络自身的错误仍会报告，若有余时可重试，但不重置棋钟。单次搜索预算与模型 / 工具调用次数上限是资源保护，不是单步计时规则。
- 练习悔棋不返还已用时间，保留已发放的加秒，撤回到人类上一手之前，并切换到重建局面的行棋方。默认比赛模式禁用悔棋；终局结算后不能悔棋。

## 多局比赛

默认三局两胜（先赢两局）；可选五局三胜（先赢三局）。比分按「人类 / 大模型」身份累计，而非按棋子颜色。

- 胜负局结束后双方交换红黑。
- 和棋不增加胜场，双方保持颜色重赛；因此总盘数可能超过 3 或 5。
- 每盘重新分配完整局时；需要手动点击「开始下一局」。
- 达到目标胜场即结束比赛，只能开始新比赛，不能继续下一局。
- 开始新比赛清空比分，当前比赛及各局已有自动保存文件不被另一局覆盖。

## 计算与 LLM

每次提交均从初始阵型完整重放棋谱并重新检查走法及将帅安全。评估记录包含合法走法、当前受将状态、阶段子力、攻防关系、附依据的专家原则，以及候选后的对方反击和交换估计。分数不是胜率，不保证最优；分析覆盖与截断显式记录，未发现风险不等于证明安全。

模型只能通过象棋扩展的 `move_piece` 工具提交一手，携带正确 revision。非法提交返回工具错误，模型可以纠正；过期、重复、已取消或超时回合均不能修改棋局。分析、走法审查、候选比较与试算只返回计算结果，不替模型下棋。无模型、无工具提交、失败或超时均明确提示，不自动用本地算法代走。

机器提交还经过独立的业务防臭棋复查：发现对方一手直接取胜的反例，或同格交换估计净亏至少 250 分，先要求模型重新考虑；若确有弃子补偿或败势不可避免，模型可以提供 12–400 字 `riskAcknowledgement` 明确说明后坚持该合法走法。说明和审查结果写入棋谱。此机制不证明弃子正确，也不改变人类走法合法性；它不会将业务推荐自动替换为落子。复查耗时计入机器棋钟，复查后再检查截止时间。具体能力与局限见 [EXPERT.md](EXPERT.md)。
