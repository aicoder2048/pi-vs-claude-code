# 调用证据：判断重读、重算和计划推进

当前请求预算为 **10次：前8次分析/读取/计划，第9–10次仅提供落子/认输**。16次工具预算不变，终局工具不会因该工具预算耗尽被封锁。预算是上限，不要求用满。

## 从哪里看

- 桌面「专家参谋」→「调用证据 · 重读、重算与计划推进」。
- 导出棋谱JSON：成功落子看 `notes[].decision.audit`，失败/取消/超时看 `attempts[].decision.audit`，机器认输看 `resignation.decision.audit`。
- `audit.version = xiangqi-call-audit/v1`；原 `chinese-chess/v1`、`xiangqi-skills/v3` 不变，此字段可选。旧棋谱缺少证据时不推测发生了什么，不能补回本次33手故障的历史读取路径。

## 记录了什么

### 每次模型请求 `requests[]`

`number`、analysis/submit阶段、完成/失败/中断状态、`stopReason`、输入/输出token数、公开文本字符数、工具调用意图数量。**不保存助手文本、thinking块、签名、提示词或请求头**。这是Pi回合编号，不等于底层HTTP重试次数。

### 每次工具调用 `calls[]`

- `id` 对应Pi的 `toolCallId`，`request` 指明属于哪次模型请求；数组按开始顺序保存，支持并行结束。可与 `timing.spans[].id = tool-${id}` 对照耗时。
- `input` 是白名单摘要：读取的逻辑 `skills/**/*.md` 路径、offset、limit；分析候选坐标、搜索深度/时间请求；计划动作、公开目标/威胁/下一步；落子坐标/版本/公开理由。
- `inputFingerprint`：原始参数规范化键序后的SHA-256；read路径转为工作区相对路径，缺省offset归一为1、limit为null（表示原生默认）。因此绝对/相对路径别名可关联；换offset/limit、候选、预算仍能区分。搜索参数缺省与显式默认值不做额外等价推断。
- `resultFingerprint`：实际工具返回content及isError的SHA-256；不保存read/bash等原始输出或文件内容。
- `result`：领域工具的有界摘要，包含搜索完成深度、根覆盖、候选评分/PV，审查风险、交换估计、反例变化/覆盖，或暂存计划的公开字段；原生工具只记输出字符数和是否错误。
- `evidenceFingerprint`：领域成功结果的上述摘要指纹，排除搜索elapsed等易变字段。原生工具/无结构错误退回完整返回指纹，**不把“同样长”当成“相同结果”**。摘要覆盖有限，不是完整语义等价。
- `sameInputAs`：同工具且同输入指纹的前一次调用ID；`sameResultAs`：同输入且实际返回指纹相同；`sameEvidenceAs`：同输入且上述结果摘要证据相同。

成功提交/认输必须在业务原子事务首次保存时完整：最后调用标记 `accepted`、`result.source = business-transaction`，**没有伪造尚未返回的结果指纹**。其余未完成调用标记 `interrupted`。错误结束、取消、超时也保留当时已捕获的请求与调用证据。

## 如何判断

1. 相同revision下同路径、同offset/limit、同结果指纹：确实重复拿到了相同返回数据，是重读候选；**不能仅据此断言无意义**，可能是确认或纠错。
2. 路径/范围不同：不是已经证实的重复读取。路径不同但结果相同，也不能自动认为用途相同。
3. 候选/深度预算不同或完成深度、覆盖、反例发生变化：有重新计算的可见依据；是否值得花时间仍需结合棋局评估。
4. 同输入、同摘要证据但原始返回不同：可能只是耗时变化，也可能有摘要未包含的变化，不能冒充全量相同。
5. `update_plan` 与read是不同动作；比较action/目标/威胁/下一步是否改变。措辞不同不保证推进，语义近似仍需人工判断。
6. 请求有公开文本但没有工具意图：记录能定位“只有文本、未提交”，不保存文本本身，因此不能评判其措辞是否重复。

这些字段是**证据，不是自动徒劳判定器**；不根据指纹阻断必要调用、修改棋局或强迫认输。

## 隐私与容量边界

- 不保存原始文件内容、shell命令、写入/编辑内容、完整工具输出、助手思考。仅技能目录下逻辑Markdown路径公开，其他路径替换为 `[redacted]`；这是日志最小化，不是文件访问沙箱或realpath授权。
- 计划和落子理由是工具协议中的公开文本，摘要限长160字；不要在公开字段中放入秘密。SHA-256也不是加密或匿名化，低熵数据可能被猜测。
- 每回合最多32个请求元数据、64个调用；调用ID超过512字符也省略并计数，技能逻辑路径超过320字符则脱敏。超出部分累计 `droppedRequests/droppedCalls`。候选最多6个、PV最多12步；结果摘要超过6000字符时标记 `summaryOmitted = size-limit`，指纹仍对应所选证据。已有失败尝试仅保留最近80项。
- 本次随成功/失败/取消/超时等现有事务保存，不为每个流式事件单独写盘。进程强杀/崩溃前尚未结算的回合不能保证保留，亦未增加完整持久Pi会话或原始网络录制。
- 新安装包会带新技能；已安装版工作区的旧技能文件不自动覆盖，需同步。开发版重启即可加载新构建。
