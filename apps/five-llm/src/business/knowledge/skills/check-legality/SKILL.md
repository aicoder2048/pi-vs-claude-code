# 合法性检查

触发：候选不确定、工具拒绝、或模型怀疑双三/双四/长连禁手。

1. 确认 ruleset=free-gomoku/v1。这里无禁手，不能套用 Renju 的黑方限制。
2. 调用 validate_move 检查 x/y 为 0..14 整数、目标为空、棋局未结束。该工具只读且不承诺占住该点。
3. 读取 winner；连续五子及以上均获胜。工具报错时修正坐标或占用，不重复同一非法请求。
4. 提交时复制当前 revision；最终还会校验业务回合、棋钟和一次性提交。

证据：合法性由 play/replay 执行，不由自然语言裁判。validate_move 不能保证提交时未超时；不开放禁手工具以免暗示错误规则。
