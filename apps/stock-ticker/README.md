# Stock Desk · 股票行情桌面应用

独立 Electron 应用，无需 API Key。输入一个 ticker 或逗号分隔的一组 ticker，展示：

- 常规交易收盘价（盘中则明确标注为最新价，不冒充收盘价）。
- 当天涨跌金额、百分比：相对上一交易日收盘价。
- 同一交易日盘后价格、涨跌金额、百分比：相对当天常规收盘价。
- 交易日期、币种、交易所时区及行情时间。

支持 Enter 查询、刷新、可选每 60 秒刷新、科技七巨头快捷填入，以及保存上次输入。单个 ticker 失败不影响其他股票。

## 运行

需要 Bun、可用网络及图形桌面环境。在仓库根目录：

```bash
just stocks-install
just stocks
```

或直接在此目录：

```bash
bun install
bun run start
```

Bun 会通过 `trustedDependencies` 执行 Electron 的安装脚本、下载桌面运行时。首次下载可能较慢。无需额外前端构建或本地服务器。

输入示例：

```text
NVDA
GOOGL, NVDA, META, MSFT, AAPL, AMZN, TSLA
BRK-B, 0700.HK
```

输入自动转大写、去重；兼容中文逗号和空白分隔。一次最多 20 个。代码遵循 Yahoo Finance 的命名规则（如伯克希尔 `BRK-B`，而非 `BRK.B`）。主要针对股票；不同交易所不一定提供盘后行情。

## 数据口径与限制

数据来自 Yahoo Finance 的公开 chart 接口，不需要密钥，但它不是有服务保障的正式授权行情 API，可能限流、延迟、改版或不可用。用于个人行情观察，不用于自动交易、再分发或商业行情服务；商业使用应先确认数据授权，改接有保障的数据供应商。

- 每个 ticker 获取常规日线和含盘前盘后的 5 分钟数据。仅从与常规价格同日的盘后时段选取最新有效价格，**不混入次日盘前或隔夜报价**。
- 盘后通常是最新 **5 分钟 K 线的区间收盘价**，并非保证实时的最后一笔成交价。界面时间为数据源的 K 线时间，不是请求完成时间；若接口提供更新的明确盘后报价，则优先使用。
- 交易时段取自行情源元数据，支持夏令时与提前收盘，不硬编码美东 16:00。交易日按交易所时区显示，获取时间按本机时区显示。
- 当天涨跌取**上一交易日日线收盘价**为基准，绝不使用多日图表的 `chartPreviousClose`（它可能是整个区间开始前的价格）。
- 缺失盘后显示 `—`。缺失上一交易日数据则不计算当天涨跌，并显示警告。没有时段元数据时不会把价格标为最终收盘。
- 非交易日显示最近一个有常规交易价格的交易日，可能不是本机“今天”；请始终查看日期。
- 自动刷新默认关闭、窗口隐藏时暂停。网络请求有超时、备用主机和并发限制；断网/失败会提示，不用零价格填补。
- 不同源、不同抓取时刻及逐笔/5 分钟数据的差异，都会使盘后价与券商、Google Finance 报价不同。

## 验证

```bash
just stocks-test                 # 离线单元测试
cd apps/stock-ticker
bun run test:smoke               # 启动真实 Electron，使用固定上游响应验证 UI/IPC
bun run test:live                # 访问真实行情接口，需联网
```

`test:smoke` 需要图形桌面，截图写入系统临时目录，不修改用户的应用数据。离线测试不会请求真实行情；真实网络测试单独运行，避免供应商故障影响单元测试。

## 结构与安全

```text
main.cjs                窗口及受来源校验/并发锁保护的 IPC
preload.cjs             仅暴露 fetchQuotes 接口
src/quotes.cjs          ticker 校验、联网、交易时段与涨跌归一化
renderer/              本地 HTML/CSS/JS，无第三方前端依赖
test/                   单元测试、Electron 冒烟测试和可选联网验证
```

Renderer 开启 sandbox 与 context isolation，关闭 Node integration。行情由主进程获取；页面 CSP 禁止直接联网、内联脚本和外部页面，阻止窗口跳转、弹窗及权限请求。外部文本通过 `textContent` 渲染。

当前交付为可本地启动的桌面应用源码，未包含安装包打包、代码签名或自动更新。
