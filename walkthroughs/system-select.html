    ② 提示词上下文

    system-select 同时动了安装和控制两段，而且走的是 Pi 1.4.0 里两条完全不同的路。工具清单（setActiveTools）改的是会话的“基础”状态：Pi 重建系统提示词的分段，并把工具增减作为 system 消息记进会话。强制提示词（before_agent_start 返回的 systemPrompt）只活在这一次 settle 里，不记进会话，每次请求时在 transformContext 里临时投影成第一条 system 消息。

    改动段生效范围记进会话吗/reload 之后
    工具清单 setActiveTools安装从下一个 turn 起，一直有效记：作为带 toolsAdded / toolsRemoved 的 system 消息保留：reload 用当前工具重建（agent-session.ts:3743）
    强制提示词 systemPrompt控制本次 settle 的所有 run、turn不记：只在 transformContext 里投影消失：activeAgent 被第 71 行清空
    状态行–（UI）到下一次 setStatus不记回到 “Default”

    小结

    system-select 第一次改提示词，而且一次用上了两条路：setActiveTools 在循环外改工具清单，Pi 把变化记进会话；before_agent_start 在 settle 外循环入口返回 systemPrompt，Pi 把它存成本次 settle 的强制提示词，每个 turn 在 transformContext 里投影到请求开头，不落盘。两条路的寿命不同，/reload 就把它们拆开了。下一篇 purpose-gate.ts 继续往入口前移：订阅 input 改写用户输入，并动态生成系统提示词。
