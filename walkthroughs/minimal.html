    ② 提示词上下文

    minimal 不写提示词，但它的进度条量的就是装配出来的上下文有多大。数据从左往右流动，minimal 在最下面读数。

    上下文在哪变大循环页脚百分比
    用户消息 / steering / follow-up 写入内 turn 开头message_end 落盘后才跳（估算）
    assistant 流式输出（message_update）内不动：页脚在重绘，但还没落盘
    assistant message_end（带 usage）内 每 turn跳到真实值（provider 返回的 token 数）
    toolResult内跳（估算）
    compaction外 run 之间变成 null，显示 0%（实际是“未知”）
    context 事件裁剪内不反映：只改本次请求，不落盘

    小结

    minimal 在循环外（session_start）装好页脚，之后每次重绘时去 L2 的 ctx 拉 L1 的状态。它不订阅任何循环事件，也不碰提示词。下一篇 pure-focus.ts。
