# 讨论记录：TillDone 的中文名与核心比喻——边牧

- **日期**：2026-10-29
- **参与**：Sean、Claude
- **用途**：统一 TillDone（扩展 `extensions/tilldone/` 与桌面端 `apps/tilldone/`）的中文名、slogan 和比喻。之后写文案、界面标签、图标、走读时，以本文为准。

---

## 1. 结论

| 项 | 定稿 |
|---|---|
| 英文名 | **TillDone**（till done，“直到完成”，并谐音 To-Do） |
| 中文名 | **边牧** |
| 英文 slogan | **Don't stop until it's done** |
| 中文 slogan | **羊不进圈，边牧不歇** |
| 一句话说明 | 你吹哨，边牧赶羊；羊不进圈，边牧不歇。 |

## 2. 比喻映射（唯一认可的版本）

**任务是羊，边牧是装上 TillDone 的 AI，用户是牧羊人。**

| 牧场 | TillDone | 对应机制 |
|---|---|---|
| 牧羊人 | 用户 | 发出指令的一方 |
| 口哨、指令 | 用户的 prompt | `input` |
| **边牧** | **装上 TillDone 的 AI**（有规矩的 agent） | — |
| 羊 | 任务（task） | `tilldone` 工具管理的列表 |
| 出栏前点数 | 先列清单才准动手 | 门禁 `gate`：无任务时拦截其他工具 |
| 一次盯住一只赶 | 先认领一个任务才干活 | 门禁：没有 `inprogress` 时拦截；同时只能有一个 `inprogress` |
| 羊进圈 | 任务完成 | 状态 `done` ✓ |
| 羊不进圈，边牧不歇 | 没做完不许停 | 督促 `agentEnd`：有未完成任务时注入 `tilldone-nudge` 并续跑 |
| 训练 | 让普通 AI 变成边牧的规矩 | 门禁和督促两套机制本身 |

## 3. 已否决的映射

**“AI 是羊，边牧是 TillDone，负责盯 AI”**：不采用。

- 和 slogan 冲突：“不歇”的是边牧，而 TillDone 里不许停的是 AI。按这个映射，slogan 会读成“AI 不进圈，TillDone 不歇”，意思拧了。
- 把 AI 比作羊（被动、笨），也把用户推到“赶 AI 的人”的位置上；比喻 B 里，用户是主人，AI 是聪明勤快的工作犬，形象更好。

由此放弃的 slogan：“它盯着，你放心”“走偏了？赶回来。”

## 4. 可用的配套文案

只要符合第 2 节的映射，下面这些都可以用：

- 副标题、启动页：**先点数，再出栏**（先列清单再动手）
- 完成感：**一只不落，全部进圈**
- 督促消息、彩蛋：**汪！还没完呢**、**别跑，还差一只**

## 5. 讨论中考虑过的其他中文名（留档）

- 功能直译：必达、做完再停、有始有终、善始善终、督办、不完不休
- 清单、收尾：销号、清零、办结、交卷、结单、闭环、盯办
- 动物：啄木鸟（笃笃）、精卫、骆驼、工蚁
- 自造词：了了、齐活、妥了、咔嗒、心安、归帆、落定

选边牧的理由：比喻关系最完整（门禁和督促都能装进“赶羊入圈”），边牧作为“最聪明、最勤快的工作犬”本身就是对 AI 的正面期许，图标也好设计。
