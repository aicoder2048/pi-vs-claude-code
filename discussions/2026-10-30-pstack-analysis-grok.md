Grok's analysis of the pstack plugin (by Lauren Tan / poteto, from cursor/plugins repo) so you can use it as reference when designing the business-layer skills for Sean's options trading agent. Here is the full rundown.

WHAT PSTACK IS: A free, MIT-licensed plugin of agent skills from Cursor engineer Lauren Tan (online name poteto, also on the React core team). Version 0.15.25 as of October 15, 2026. Core idea: "if you want to go fast, go deep first" — write less code of higher quality, not maximize lines of code. It turns the agent into a real engineering team with rigorous workflows: match task to playbook, delegate to subagents, multi-model review, verify on the real app before reporting success.

SEVEN COMPONENT BLOCKS:
1. Core skill: /poteto-mode — the entry point for any non-trivial task. Reads the request, selects a playbook, creates a todo list, routes to other skills, spawns subagents, writes a clean reply.
2. 23 playbooks under skills/poteto-mode/playbooks/: investigation, bug-fix, perf, hillclimb, runtime-forensics, trace-forensics, feature, refactoring, prototype, visual-parity, authoring-a-skill, eval, babysit, shipping, autonomous-run, orchestrate, autopilot-full, autopilot-stack, session-pickup, pause-safely, multi-phase-plan, worktree-cleanup, opening-a-pr. Each is a specific workflow; poteto-mode copies its steps verbatim into a todo list, skipped steps stay with a reason.
3. 24 principle short skills (principle-*.md): one-sentence engineering rules grouped by core, architecture, verification, delegation, meta. Examples: "fix the root cause, not the symptom", "prove it works", "subtract before you add", "laziness protocol". poteto-mode indexes them inline and reads the index at task start.
4. ~30 workflow skills: explanation (how, why, recall, ketchup, ketchup-video), safety/impact (blast-radius, architect), parallelism (arena: run N parallel attempts and merge best parts; swarm: spawn N workers on different slices), review (interrogate: multiple models try breaking a diff, keep only proven findings; no-comments: strip comments, spawn Comment Sicko), plus tdd, reflect, correct, automate-me, make-bot-ui, setup-pstack, teach, benchmark-checklist, typescript-best-practices, create-verification-skill, maintain-verification-skill, create-formal-verification-skill, maintain-formal-verification-skill, statechart, unslop, bro, technical-writing, show-me-your-work, figure-it-out (fallback when no playbook fits: designs a bespoke auditable playbook), in-your-own-words, sharpen, poteto-help.
5. Two subagents: poteto-agent (delegate for code-writing; must read the full poteto-mode SKILL.md including principles index before any work; spawn fresh per task) and comment-sicko (read-only comment reviewer invoked via /no-comments).
6. Rules config: /setup-pstack detects available models, asks for a reasoning budget (xhigh default, unlimited, medium, small), assigns models to roles (code delegates, judgment, review panels, swarm workers) and writes ~/.cursor/rules/pstack-models.mdc which every pstack skill reads. Roles without a line keep skill defaults.
7. Helper scripts and dormant automations: generate-pstack-harness-trees.mjs (generates the Claude Code harness copy; CI enforces freshness), and automations/benny/ (Slack issue triage, not registered as slash skills).

HOW POTETO-MODE ORCHESTRATES: Its SKILL.md contains the principles index, read at task start. It parses the request, matches one playbook, copies steps verbatim into a todo list. Code steps spawn a fresh poteto-agent that reads poteto-mode fully before starting. Multi-model review goes through interrogate or arena. Diffs can go through no-comments to Comment Sicko. Decisions log to show-me-your-work TSV. If no verify skill exists, create-verification-skill generates a project-local one teaching the agent to drive the app like a user. The coupling mechanism across all components is the shared todo-list file plus the always-applied rules file.

INSTALL: Cursor: /add-plugin pstack then /setup-pstack. Claude Code: /plugin marketplace add cursor/plugins then /plugin install pstack@cursor-plugins (commands get a pstack: prefix there). Skills are plain SKILL.md files decoupled from Cursor's plugin format — a community port (michael-denyer/pstack-claude) adapts them for Codex, Pi, GitHub Copilot, Muse, etc.

RELEVANCE TO SEAN'S PROJECT: Sean is building a 4-layer options trading agent (Pi runtime, TypeScript extension hooks, Python business logic, interface layer) with TDD + mutation testing. pstack's patterns map well: poteto-mode as the orchestrator skill, playbooks for task types (e.g., options-chain analysis, risk-check, order-draft, fault-tolerance), principles as one-line guardrails, subagents for isolated execution (e.g., a risk-reviewer subagent), the model-assignment rules file, and verification skills that prove strategy behavior on real data before trusting output. The key architectural lesson: skills define process, subagents provide execution and isolation, rules broadcast config, and a shared artifact (todo list / state file) couples them — same pattern Sean already uses with file-based state in his agent loop.
