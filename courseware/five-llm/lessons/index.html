弈境结构精读

弈境（apps/five-llm）是一个人机五子棋桌面应用。它的机器棋手是一个 LLM，必须通过工具调用才能落子。本课程精读它的技术白皮书和后续设计记录，按代码现状讲透四层架构、Pi SDK 接入、双循环接入点、知识包与上下文工程、连续冲四门禁。每课有结构图、互动演示和自测。右侧的 AI 助教读过白皮书、勘误和相关源码。

名字相近，不要混“拾伍”（apps/five）是离线五子棋，没有 LLM。“楚河”（apps/chinese-chess）是同一套做法的象棋版。“边牧”（apps/tilldone）是另一门课：它用 RPC 子进程接 Pi，弈境用进程内 SDK。L03 会对照两者。

怎样用这些课程

  1. 先读“学完本课，你能够”：知道这一课要带走什么。
  2. 看结构图：每课先给结论，再用图把结构和流程画出来。
  3. 动手玩演示：调参数、换场景，看设计在什么条件下有效、什么时候有代价。
  4. 做自测题：每课最后有 3–5 道题。答错会显示解释。
  5. 问 AI 助教：右侧的 AI 助教读过原文和本课全部内容。可以选中一段话问它，或点图片、演示右上角的“问 AI”。
启用 AI 助教在终端运行 cd lessons && uv run --no-project python tools/serve.py，然后打开 http://127.0.0.1:8772/lessons/。模型是 DeepSeek（默认 deepseek-flash），走 DeepSeek 官方 API，按量计费。API key 放在 lessons/.env，只在本机服务里用，不进页面。直接双击打开 HTML 也能学，只是没有 AI 助教。
